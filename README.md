# CottonVPN

Клиент CottonVPN для Android — простой и быстрый VPN: вставь ключ из бота и нажми кнопку.

### [Сайт](https://cottonvpn.com) | [Telegram-бот](https://t.me/cottonvpn_bot)

## Возможности

- Подключение одним нажатием — ключ выдаёт [@cottonvpn_bot](https://t.me/cottonvpn_bot)
- Обфусцированный протокол — работает там, где обычный VPN блокируется
- Режим «Российские сервисы напрямую» — банки, Госуслуги и карты в обход VPN
- Трафик и остаток дней подписки прямо на главном экране
